# HOPPETS Product Manager

## Descripción

HOPPETS Product Manager es una aplicación web desarrollada como proyecto académico para la asignatura Integración Continua.

La plataforma permitirá gestionar productos para mascotas mediante una interfaz web intuitiva, facilitando la administración de inventario básico y la consulta de información por parte de los clientes.

## Objetivo

Desarrollar una aplicación web que permita administrar y consultar productos para mascotas de forma eficiente.

## Funcionalidades Iniciales

- Visualización de productos.
- Consulta de precios.
- Consulta de disponibilidad.
- Gestión de productos.
- Actualización de stock.
- Administración mediante panel interno.

## Tecnologías

- ASP.NET Core
- SQL Server / SQLite
- Docker
- GitHub
- Render
